# TenderPilot Prompt Pack - START HERE

Ce pack complete la documentation fonctionnelle TenderPilot deja definie.

Ordre recommande :
1. Lire `01_GUIDE_DE_LECTURE_ET_DEPENDANCES.md`.
2. Lire `02_GUIDE_AGENT.md` avant d'envoyer un prompt a un agent IA.
3. Utiliser les prompts dans `01_PROMPTS/` dans l'ordre B -> R.
4. Utiliser `03_GUIDE_OPERATEUR_GEORGEO.md` pour presenter, configurer, tester et livrer le produit.
5. Conserver la documentation precedente comme reference fonctionnelle principale.

Principe : le produit doit rester utilisable manuellement. L'automatisation, Python, Telegram et l'IA sont des couches optionnelles.
