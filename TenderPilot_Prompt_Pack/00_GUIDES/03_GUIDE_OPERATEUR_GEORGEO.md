# Guide operateur - presenter, configurer et livrer TenderPilot

## 1. Comment presenter TenderPilot
Ne pas dire : "c'est un Excel avec de l'IA".
Dire : "TenderPilot est une boite a outils de veille, qualification, preparation et suivi des opportunites. Il centralise les sources, aide a prendre une decision Go/No-Go, structure les exigences, accelere la preparation des offres et suit les deadlines."

## 2. Demo ideale en 10 minutes
1. Ouvrir le Dashboard.
2. Montrer une nouvelle opportunite.
3. Montrer la deadline et la couleur automatique.
4. Ouvrir le Go/No-Go.
5. Montrer un critere eliminatoire.
6. Ouvrir la Compliance Matrix.
7. Montrer une reference et un expert proposes.
8. Montrer le template technique/financier.
9. Montrer une analyse IA.
10. Montrer une notification Telegram ou email.

## 3. Configuration client
Collecter : pays cibles, secteurs, types d'opportunites, budget minimum, langues, mots-cles, profil organisation, documents, references, experts, emails d'alerte.

Configurer ensuite : Sources -> Watchlist -> Organization Profile -> References -> Experts -> Command Center -> Deadlines -> Automations -> IA -> Notifications.

## 4. Test avant livraison
- Ajouter une opportunite DEMO.
- Verifier deadline et couleurs.
- Tester Go/No-Go.
- Tester critere obligatoire manquant.
- Tester analyse PDF/texte.
- Tester rappel.
- Tester soumission marquee "Soumis".
- Tester expiration document.

## 5. Livraison client
Livrer : dossier Toolkit, copie Google Sheet, guide installation, video courte, configuration initiale si incluse, note sur les limites de scraping/API.

## 6. Support
Distinguer :
- support utilisation ;
- configuration ;
- ajout d'une nouvelle source ;
- maintenance d'un scraper ;
- personnalisation de templates.

## 7. Discours commercial
Valeur : gagner du temps, reduire les oublis, mieux filtrer les opportunites et professionnaliser la preparation. Ne jamais promettre de gagner un marche.

## 8. Maintenance
Tous les 60-90 jours : verifier les sources, APIs, formules, scripts, quotas et modeles IA. Conserver un changelog.
